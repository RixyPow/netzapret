# ARC Raiders: игровые серверы — сети, куда игра шлёт UDP матча.
#
# Серверы — выделенные, в Google Cloud (Embark строит на нём свою
# инфраструктуру; игрок в обсуждении №32 — «сервера гугловские у игры»), и
# адрес у каждого матча свой: ускоритель lightspeed (github.com/ShibbityShwab/
# lightspeed, профиль arcraiders.rs, замер 18.10 на живой установке) видел
# порты 7777 и 7600 и случайные выше 31000. Готового перечня нет ни у кого,
# а весь Google Cloud в туннель — это половина интернета. Поэтому список
# пополняется сам: пока часть стоит «через VPN» и запущен PioneerGame.exe,
# «Наблюдение» видит соединения игры и дописывает сюда адрес без имени сетью
# /24 (GameServerLearn). Работает после перезапуска движков — маршруты TUN
# движок берёт при запуске.
#
# Для начала — адрес бэкенда игры, api-gateway.europe.es-pio.net (21.10):
