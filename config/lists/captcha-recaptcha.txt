# Капча Google — reCAPTCHA.
#
# Отдельная часть «Капч» с 01.10. Капча идёт своим путём, а не путём сайта,
# который её показывает: сайт через VPN, а капча с домашнего адреса —
# и проверка отказывает (так было с hCaptcha у Discord 30.09; почему именно —
# не выяснено, догадка: сверка адреса).
#
# Здесь только recaptcha.net — запасное имя, которым пользуется часть сайтов.
# Основное — путь www.google.com/recaptcha, а правило по пути не бывает:
# эта капча идёт тем же путём, что и весь www.google.com (список Google).
#
# recaptcha.net лежит и в google.txt. Пока у этой части нет своего выбора,
# решает правило Google; выбранная, она встаёт раньше него (Within).
recaptcha.net
