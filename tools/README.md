# Движки

Сюда кладутся исполняемые файлы, которыми NetZapret управляет. Сами они
в репозиторий не входят: у них своя версионность и свои лицензии, а весят они
десятки мегабайт. Каталог отслеживается только ради этого файла.

## Что попадает в сборку

`build.cmd` складывает движки в `build\engines\`, чтобы собранная копия работала
сама по себе, не требуя ни установленного Zapret, ни распакованного sing-box:

| Куда | Откуда | Размер |
| --- | --- | --- |
| `engines\sing-box\` | каталог с `sing-box.exe` из `tools\` | ~53 МБ |
| `engines\zapret\` | `exe`, `lists`, `lua`, `bin`, `windivert.filter`, `presets\winws2` | ~15 МБ |

Каталог sing-box копируется целиком, а не одним файлом: рядом лежит `wintun.dll`,
без которого TUN не поднимется, и сборка с одним `.exe` собралась бы успешно,
а сломалась при запуске без внятной причины.

Из установки Zapret берётся только то, что читает движок. Она занимает 219 МБ,
из которых 120 — Python-рантайм графической оболочки, а 61 — её логи; ни то,
ни другое нам не нужно.

Пресеты копируются только из `presets\winws2`. `winws1` — предыдущий движок,
мы его не запускаем, а `winws2_builtin` программа не читает вовсе: она смотрит
в `winws2` и только туда. Из линейки Universal в сборку не попадает всё ниже
V5 — эти вытеснены пятой и шестой версиями, а меню из девяти почти одинаковых
строк усложняет выбор, а не обогащает его.

Отбор касается только сборки. В вашей установке остаются все пресеты, и любой
можно вернуть, скопировав файл в `build\engines\zapret\presets\winws2`.

Встроенная копия имеет приоритет над установленной в системе — она версионируется
вместе с программой, тогда как установка обновляется своей жизнью, и пресет,
на который мы ссылаемся, может измениться или исчезнуть. Если встроенной копии
нет, программа откатывается на системную установку.

Копирование происходит при сборке, а не через репозиторий. Списки — данные
Zapret, они меняются вместе с ним, и копия в git за недели превратилась бы
в устаревший форк чужой работы.

**О лицензиях.** В `engines\zapret\exe` попадают `cygwin1.dll` (GPLv3) и WinDivert
(LGPL/GPL). Для личной сборки это ничего не меняет, но публикация релиза с этими
файлами накладывает обязательства — учитывайте, если соберётесь выкладывать
готовые архивы.

## sing-box — обязателен для VPN

Скачать с [github.com/SagerNet/sing-box/releases](https://github.com/SagerNet/sing-box/releases)
сборку `windows-amd64` и положить сюда `sing-box.exe`.

Проверялось на 1.13.19. Более старые не подойдут: с 1.12 обязательно поле
`default_domain_resolver`, а действие `reject` в правилах маршрутизации
появилось в 1.11 — на нём держится обход DoH.

Проверить, что нашёлся:

```bash
nz doctor
```

## xray — пока не используется

Два сервера с VLESS + REALITY подключаются в Xray и не подключаются в sing-box
(`reality verification failed`). Поддержка Xray вторым движком запланирована;
до неё файл здесь ни на что не влияет.

## Zapret — отдельная установка, не сюда

winws2 берётся из вашей установки Zapret 2, вместе с пресетами, hostlist'ами
и ipset'ами. NetZapret читает их как есть и ничего не копирует: списки живут
своей жизнью и обновляются вместе с Zapret, а копия быстро превратилась бы
в устаревший форк чужих данных.

Установка ищется сама; где именно нашлась, показывает `nz doctor`.
