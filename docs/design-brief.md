# NetZapret — бриф для дизайнеров

Документ описывает то, что есть сейчас: экраны, окна, палитру, пути
пользователя и места, где движение уместно. Всё перечисленное взято из кода,
а не из памяти.

---

## 1. Что это за программа

Настольное приложение под Windows, которое обходит блокировки. Внутри два
движка: **десинк** (правит сетевые пакеты так, чтобы фильтр оператора не узнал
имя сайта) и **VPN** (туннель через зарубежный сервер). Программа решает, что
пустить каким путём.

Аудитория — не сетевые инженеры. Человек приходит с «не открывается Discord»
и должен уйти с работающим Discord, не выучив слова «десинк».

**Важное следствие для дизайна:** половина текста в интерфейсе — объяснения.
Их нельзя выкидывать ради чистоты макета, но можно организовать лучше.

---

## 2. Чем это сделано

| | |
|---|---|
| Платформа | Windows, .NET 8, **WPF** (не веб, не Electron) |
| Разметка | XAML — своя система, на CSS не похожа |
| Окно по умолчанию | **1080 × 720**, изменяемое |
| Шрифт интерфейса | **Segoe UI** (системный) |
| Шрифт моноширинный | **Cascadia Mono**, запасной Consolas |
| Языки | только русский |
| Права | запускается от администратора |

### Что это значит на практике

**Своих шрифтов нет и не будет просто.** Подключить файл шрифта в WPF можно,
но он поедет в поставку и увеличит её. Если вы хотите другой шрифт — назовите
его, обсудим цену.

**Анимации возможны, но иначе, чем в вебе.** В WPF есть Storyboard: можно
двигать, менять прозрачность, цвет, размер. Нет ничего похожего на CSS-фильтры,
блюр за элементом, сложные тени. Сейчас анимаций в интерфейсе **нет ни одной** —
это чистое поле.

**Скруглений и теней немного.** Они есть, но каждое надо описывать вручную.
Сложные эффекты дороги.

## 3. Палитра

Тем две, переключаются мгновенно. Ключи в обеих совпадают до последнего —
это условие: элементы про тему не знают, меняется только набор цветов.

**Если вы добавляете цвет — он обязан появиться в обеих темах.**

| Ключ | Тёмная | Светлая | Что это |
|---|---|---|---|
| `Backdrop` | `#0D1117` | `#F6F8FA` | фон окна |
| `Surface` | `#161B22` | `#FFFFFF` | карточки |
| `Raised` | `#1C2128` | `#F0F3F6` | приподнятое: поля, строки списка |
| `Border` | `#30363D` | `#D0D7DE` | границы |
| `Text` | `#E6EDF3` | `#1F2328` | основной текст |
| `Muted` | `#8B949E` | `#636C76` | второстепенный текст |
| `Faint` | `#6E7681` | `#8C959F` | подписи, отключённое |
| `Accent` | `#3FB950` | `#1A7F37` | «работает», зелёный текст |
| `AccentDim` | `#2EA043` | `#116329` | нажатое состояние |
| `AccentFill` | `#2EA043` | `#2DA44E` | заливка главной кнопки |
| `OnAccent` | `#06110A` | `#FFFFFF` | текст на заливке |
| `Danger` | `#F85149` | `#CF222E` | «не работает» |
| `Warn` | `#D29922` | `#9A6700` | «требует внимания» |
| `WarnFill` | `#D29922` | `#D4A017` | заливка жёлтого |

Родословная видна: это близко к палитре GitHub. Менять можно, но три цвета
состояния несут смысл и читаются во всех таблицах — **зелёный «работает»,
жёлтый «требует внимания», красный «не работает»**. Если меняете их, смысл
должен сохраниться.

### Уже наступленные грабли

На светлой теме заливку и текст пришлось развести. Зелёный, читаемый как
текст на белом, обязан быть тёмным — а тёмная кнопка с тёмной подписью
сливается в грязь. Отсюда отдельные `AccentFill` и `OnAccent`.

## 4. Карта экранов

Слева вертикальное меню на 11 пунктов, справа содержимое. Меню всегда на месте.

| Раздел | Что там |
|---|---|
| **Главная** | состояние движков, кнопка «Запустить», полоса состояния |
| **VPN** | подписка, список серверов, замер задержки, выключатель WARP |
| **Десинк** | выбор пресета, список пресетов с перетаскиванием |
| **Маршруты** | 26 сервисов, разложенных по частям: каждой части свой маршрут |
| **Проверка блокировок** | таблица из ~120 имён: что открыто, что закрыто, чем лечится |
| **DNS** | выбор резолвера, DoH |
| **Файл hosts** | прибитые адреса |
| **Наблюдение** | живой список соединений |
| **Журнал** | три файла журналов на выбор |
| **Диагностика** | самопроверка: что не так с установкой |
| **Ещё** | тема, обновления, прочие настройки |

## 5. Все всплывающие окна

### 5.1 Свои окна — три штуки

Все модальные, размер **720 × 620**, минимум 560 × 420.

---

#### «Чем чинить имя» — выбор рецепта десинка

Самое сложное окно программы и главный кандидат на переделку.

**Структура сейчас:**
```
Заголовок:  Чем чинить discord media — проверяю на probe.discord.media
Пояснение:  два абзаца про то, что такое рецепт
Статус:     Открывают 3 из 8. Берите любой из отмеченных…

Список карточек, у каждой:
    название приёма          hostfakesplit_multi
    состав моноширинным      hostfakesplit_multi:hosts=google.com,vimeo.com:…
    где применяется          в пресете: updates.discord.com, discord.com, itch.io
    вердикт                  открывается / не помогает / проверяю…
    кнопка                   выбрать

Низ:  пояснение про «решает пресет»
      [Проверить все]  [Решает пресет]  [Отмена]
```

**Что здесь болит:**
- Восемь карточек с моноширинными строками по 80 символов — стена текста.
- Вердикт «открывается» появляется по одному, с задержкой 1–4 секунды
  на каждый. Сейчас это просто смена цвета текста.
- Зелёная обводка у сработавших есть, но карточки всё равно сливаются.
- Человек не понимает, чем `hostfakesplit` отличается от `hostfakesplit_multi`,
  и выбирает наугад.

**Что можно сделать:** дать состоянию проверки визуальный язык — ожидание,
проверка, успех, неудача. Сейчас всё это разница в оттенке слова.

---

#### «Пин в hosts» — прибить имя к адресу

```
Заголовок:  Пин в hosts
Поле:       имя
Список:     найденные адреса с задержкой у каждого
Кнопки:     закрепить / отмена
```

Смысл: сайт лежит на десятке адресов, часть заблокирована, часть нет.
Окно находит рабочий и записывает его в системный файл.

---

#### Выбор цели проверки

Список сервисов и отдельных имён, чтобы не гонять все 120 разом.

---

### 5.2 Системные диалоги Windows — четыре штуки

Выглядят как стандартные окна Windows, не наши. **Хороший кандидат заменить
на свои** — сейчас они выбиваются из оформления.

1. **«Пресет уже есть. Заменить?»** — Да / Нет
2. **«Снять пин с {имя}?»** — ОК / Отмена, с пояснением о последствиях
3. **Подтверждения в «Ещё»** — Да / Нет, с иконкой предупреждения
4. Прочие подтверждения опасных действий

---

### 5.3 Встроенные полосы — не окна

**Полоса «Перезапустить Discord»** — появляется внизу после смены маршрута.
Кнопки «Позже» и «Перезапустить». Сейчас просто возникает без движения.

**Полоса состояния** под карточкой на «Главной». Цвет несёт смысл:
серый «стоит», жёлтый «поднимается», зелёный «работает», красный «не работает».

## 6. Логика действий для новичка

Программа сейчас **не ведёт** нового человека. Он попадает на «Главную»
и видит кнопку запуска. Всё остальное надо найти самому.

### Что происходит при первом запуске

```
1. Окно открывается на «Главной»
2. Движки остановлены, полоса серая
3. Пресет уже выбран по умолчанию — Universal V8
4. Подписки VPN нет: поле пустое
5. Нажатие «Запустить» поднимает десинк; VPN не поднимется без подписки
```

### Чего новичок не знает и негде узнать

- Что такое пресет и зачем их восемь штук в списке
- Чем «десинк» отличается от «напрямую» и от «через VPN»
- Что для VPN нужна **своя** подписка, программа её не даёт
- Что после смены маршрута надо перезапустить движки
- Что проверка рецептов требует **остановленных** движков

Последнее — живая боль: человек жмёт «Проверить все», а в ответ строчка
внизу окна, которую он не замечает.

### Что просится

**Первый запуск как отдельный сценарий.** Три-четыре шага: что вы хотите
починить → есть ли подписка → пробный запуск → результат. Сейчас этого нет
совсем, и это самая большая дыра.

## 7. Типичный путь пользователя

### Сценарий А — «у меня не открывается сайт»

Самый частый.

```
Главная → Запустить
       ↓ не помогло
Проверка блокировок → прогнать
       ↓ видит «DPI по TLS» у нужного имени
Маршруты → найти сервис → поставить «десинк»
       ↓ открывается окно выбора рецепта
       ↓ но движки работают — проверка отказывается идти
Главная → Остановить
Маршруты → снова → Проверить все → выбрать рабочий
Главная → Запустить
```

**Семь переходов между разделами.** Из них два — возврат за тем, что надо
было сделать раньше. Это и есть главная беда навигации.

### Сценарий Б — «хочу VPN»

```
VPN → вставить ссылку подписки → загрузить
    → список серверов с задержками
    → выбрать или оставить автоподбор
Маршруты → выбрать, что пускать через VPN
Главная → Запустить
```

Ровнее, потому что всё в одном месте.

### Сценарий В — «всё сломалось после обновления»

```
Диагностика → самопроверка
Журнал → посмотреть, что пишет движок
```

Оба раздела сейчас — стены моноширинного текста.

## 8. Где можно анимировать

Анимаций сейчас **ноль**. Перечислено по убыванию пользы.

### Высокая польза

**1. Проверка рецептов — состояние каждой карточки.**
Восемь карточек проверяются по очереди, каждая 1–4 секунды. Сейчас меняется
только цвет слова. Нужен язык состояний: ожидает → проверяется → результат.
Бегущая засечка, пульс, что угодно, лишь бы было видно движение.

**2. Полоса состояния на «Главной» при запуске.**
Движки поднимаются 2–5 секунд. Полоса просто меняет цвет с серого на жёлтый
и потом на зелёный. Просится заполнение или пульсация на жёлтом.

**3. Появление полосы «Перезапустить Discord».**
Сейчас возникает мгновенно и этим пугает. Выезд снизу за 200 мс.

**4. Замер задержки серверов VPN.**
Список из двадцати строк, у каждой появляется число. Сейчас числа просто
возникают.

### Средняя польза

**5. Смена темы.** Сейчас мгновенная подмена всех цветов. Переход за 150 мс
был бы мягче. Технически: анимировать цвета кистей, а не подменять словарь.

**6. Раскрытие сервиса в «Маршрутах».** Папки раскрываются рывком.

**7. Переход между разделами.** Сейчас мгновенная подмена. Лёгкое проявление.

**8. Таблица проверки блокировок.** 120 строк появляются по мере проверки,
каждая рывком.

### Осторожно

**Значки сервисов** подгружаются с сайтов и появляются с задержкой. Анимировать
их появление можно, но помните: у части сервисов значка не будет никогда,
и на его месте стоит буква.

### Чего делать не стоит

Долгих переходов между разделами — программой пользуются в момент, когда
что-то не работает, и человек раздражён. Всё, что дольше 200 мс, будет
мешать.

## 9. Что можно сделать

По убыванию отдачи.

1. **Сценарий первого запуска.** Его нет совсем.
2. **Окно выбора рецепта.** Самое сложное место программы.
3. **Свои диалоги вместо системных.** Четыре штуки, выбиваются из оформления.
4. **Навигация в сценарии А.** Семь переходов надо сократить.
5. **Журнал и диагностика.** Стены моноширинного текста.
6. **Иконки разделов.** Сейчас меню — просто слова.
7. **Пустые состояния.** Нет подписки, нет журнала, ничего не найдено —
   сейчас везде просто пусто.

## 10. Что прислать обратно

**Формат:** Figma, ссылка на файл с правом просмотра.

**Размеры макетов:**
- Основное окно **1080 × 720** и растянутое до **1440 × 900**
- Модальные окна **720 × 620**

**Обязательно:**
- Обе темы для каждого макета
- Названия цветов из таблицы раздела 3, а не hex в отрыве от смысла
- Состояния кнопок: обычное, наведение, нажатие, отключённое
- Что делать с длинным текстом: почти везде русский, строки длиннее английских

**Хорошо бы:**
- Отдельный слой с тем, что вы предлагаете анимировать, с длительностями
- Сетка отступов, если предлагаете свою

**Не нужно:**
- Готовых ассетов в SVG — WPF их не ест напрямую
- Своих шрифтов без предварительного разговора
- Иконок в растре: нужен вектор или системный шрифт значков

## 11. Живые снимки

Скриншоты текущего состояния можно снять самим: программа собирается из
исходников. Разделы, которые стоит посмотреть обязательно:

- **Маршруты** — самый плотный экран, 26 сервисов с раскрытием
- **Проверка блокировок** — таблица на 120 строк
- **Окно выбора рецепта** — то, что переделывать в первую очередь
- **Ещё → Оформление** — переключатель тем, чтобы увидеть обе
