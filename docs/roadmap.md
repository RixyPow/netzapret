## Импорт пресетов zapretgui

Пресеты winws2 лежат в `C:\Zapret\Dev\presets\winws2\`. Формат:

```
# Preset: Universal V6
# BuiltinVersion: 2.26
# IconColor: #ff7b72
# Description: ...

--lua-init=@lua/zapret-lib.lua        # глобальные ключи
--blob=tls_google:@bin/...
--wf-tcp-out=80,443-65535

--new                                  # разделитель секций

--name=youtube.com (интерфейс)
--filter-tcp=80,443                    # селекторы
--hostlist=lists/youtube.txt
--out-range=-d8
--lua-desync=multidisorder:pos=1,...   # рецепт
```

Значимые свойства формата:

* порядок секций важен — выигрывает первая совпавшая;
* `--lua-desync=pass` означает «не трогать», это явное исключение;
* цель сопоставления задаётся либо доменами (`--hostlist`, `--hostlist-domains`),
  либо адресами (`--ipset`), либо протоколом L7 (`--filter-l7`).

Зачем это NetZapret: чтобы он знал, какие домены **уже** покрыты десинком, и
режим `desync` в правилах согласовывался с секциями пресета, а не дублировал их.
Разбор должен быть только на чтение — редактировать пресеты продолжает Zapret GUI.

## VPN-интерфейс

Ориентир — клиент Happ. Что из этого влияет на модели данных:

* **группы подписок**, а не плоский список серверов;
* у группы — квота трафика (`44GB / ∞`), дата истечения, интервал автообновления;
* у сервера — страна, бейдж транспорта (`VLESS / XHTTP / TLS / JSON`), задержка;
* **тест пинга** по всем серверам группы;
* переключатель режима **Proxy / TUN**.

Последнее особенно важно для сосуществования с Zapret: в режиме Proxy трафик
идёт через локальный SOCKS/HTTP и TUN не поднимается вовсе, так что WinDivert
видит исходные потоки. Это фактически безопасный режим по умолчанию, пока
поведение десинка при поднятом TUN не измерено.
