# Description: Перевод general (ALT11).bat из zapret-discord-youtube (Flowseal) с Zapret 1 на Zapret 2, game filter включён. Заведён 25.09 для сравнения с Universal V10: пользователи пишут, что у Flowseal быстрее YouTube. Списки — те же, что у Flowseal (list-general, list-google, ipset-all).

# ---------------------------------------------------------------------------
# Как переведено. Оригинал — winws.exe (Zapret 1), ключи --dpi-desync=…;
# здесь winws2 и --lua-desync=…. Соответствие по справке модулей Lua
# (zapret-antidpi.lua, zapret-lib.lua):
#
#   --dpi-desync=fake,multisplit      → fake, затем multisplit
#   --dpi-desync-fooling=ts           → tcp_ts=-1000, только у fake:
#                                       в Zapret 1 обман ставится подделкам,
#                                       а у multisplit он портил бы настоящие
#   --dpi-desync-repeats=N            → repeats=N у fake
#   --dpi-desync-split-pos=1          → pos=1
#   --dpi-desync-split-seqovl=N       → seqovl=N
#   --dpi-desync-split-seqovl-pattern → seqovl_pattern=<образец>
#   --dpi-desync-fake-tls / -http     → отдельный fake с payload=tls_client_hello
#                                       или payload=http_req — по fake на образец
#   --dpi-desync-fake-quic            → fake с образцом QUIC
#   --ip-id=zero                      → ip_id=zero
#   --dpi-desync-any-protocol=1       → --payload=all
#   --dpi-desync-cutoff=n4            → --out-range=-n4
#   %GameFilterTCP%, %GameFilterUDP%  → 1024-65535: game filter включён,
#                                       как у пользователя, который об этом
#                                       и попросил
#
# Отступления от оригинала, и все намеренные:
#
# 1. discord.media — файлом lists/discord-media.txt, а не
#    --hostlist-domains=discord.media. Справка winws2 называет инлайновый
#    список «FIXED domain list»: поддомены он не покрывает, а голосовые
#    серверы Discord — поддомены. См. CLAUDE.md, раздел «Пресеты».
# 2. У секций по адресам (ipset-all) нет --hostlist-exclude. Исключение
#    по имени превращает профиль по адресам в профиль по именам, и пакет
#    без имени ему уже может не достаться — так у нас однажды пропал голос
#    Discord (WinwsCommandLine.FiltersByName). --ipset-exclude остаётся.
# 3. Списки *-user.txt Flowseal не переносятся: они личные, у нас на их
#    месте свои маршруты и щит «напрямую».
# 4. --out-range=-d8 у TCP и -n8 у UDP, как во всех наших пресетах:
#    без окна приём применяется к каждому пакету соединения. Подделки
#    и разрезы Zapret 1 срабатывают только на первом пакете с данными,
#    так что окно их не урезает.
#
# Не проверено на живой сети — пресет для сравнения, а не замена V10.
# ---------------------------------------------------------------------------

--lua-desync=fake:blob=quic_google:repeats=11
