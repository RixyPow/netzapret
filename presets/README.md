# Пресеты

Это единственное место, откуда программа берёт пресеты. Что положено сюда,
то и предлагается в меню; чего здесь нет, того для неё не существует.

Пресеты и их формат — из [Zapret GUI](https://wiki.zapret.moe/), автор —
loop-uh, лицензия MIT. Часть лежит здесь без изменений, часть изменена,
Universal V8–V10 и V11 Lite собраны уже в этом проекте из тех же секций. Разбор —
в [docs/THIRD-PARTY.md](../docs/THIRD-PARTY.md).

Старше V8 «Universal» здесь нет: 08.10 по слову владельца убраны V5, V5
(game filter), V5 my, V6, V6 voicefix, V7 и V8 diag. Обновление новые файлы
кладёт, а лишние не стирает — у тех, кто обновился, они остаются на диске.

«white sni (circular)» и «shadow probes (circular)» (с 08.10) нужны модули
lua Zapret GUI от 07.10 и новее (`shadow_probe`, `white_seqovl`, детекторы
`white_*` в `custom_funcs.lua`): со старой установкой Zapret GUI winws2
с ними не поднимется.

Установка Zapret больше не читается. У неё две папки и полторы сотни файлов,
почти все — переборные варианты одной стратегии, и решать за человека, какие
из них показать, приходилось нам. Всякий такой выбор оказывался спорным,
а набор к тому же менялся под нами при каждом обновлении Zapret.

## Как добавить

Положить файл `.txt` сюда. Появится в списке при следующем заходе в меню —
перезапускать программу не нужно.

Открыть эту папку из программы: **Пресет Zapret → п**.

## Что внутри пресета

Формат winws2, как его пишет Zapret GUI:

```
# Preset: Universal V6
# BuiltinVersion: 2.26

--lua-init=@lua/zapret-lib.lua     # глобальные ключи
--wf-tcp-out=80,443-65535

--new                              # разделитель секций

--name=youtube.com (интерфейс)
--hostlist=lists/youtube.txt       # путь от корня установки Zapret
--lua-desync=multisplit:pos=2
```

Пути внутри — `lists/`, `lua/`, `bin/` — отсчитываются от корня установки
Zapret, а не от этой папки: рабочим каталогом при запуске winws2 остаётся
именно он. Поэтому списки доменов по-прежнему берутся оттуда, и Zapret нужен,
даже когда пресеты свои.

## Одинаковые названия

Заголовок `# Preset:` уникальным быть не обязан. Два файла с одним заголовком
показываются с именем файла в скобках — иначе между ними не выбрать.
