# Темы NetZapret

Тема — папка здесь, в `themes\`, с файлом `theme.json` внутри. Рядом можно
положить картинку фона и шрифты. Программа находит темы сама: «Ещё» →
«Оформление».

Проще всего начать с копии `dark` или `light` — или указать основу
и задать только своё:

```json
{
  "name": "Моя тема",
  "author": "Имя художника",
  "base": "dark",
  "colors": {
    "backdrop": "#000000",
    "accent": "#F2D335",
    "accent-fill": "#F2D335"
  },
  "fonts": {
    "display": "Bahnschrift Condensed",
    "files": ["fonts/MyDisplay.ttf"]
  },
  "background": {
    "image": "background.jpg",
    "fit": "cover",
    "dim": 0.6,
    "blur": 24
  }
}
```

## Цвета — 14 слотов

| Слот | Что красит | С чем обязан читаться |
|---|---|---|
| `backdrop` | фон окна | — |
| `surface` | карточки, строки | — |
| `raised` | кнопки, поля, выбранное | — |
| `border` | рамки, разделители | — |
| `text` | основной текст | 4.5:1 на `backdrop`, `surface`, `raised` |
| `muted` | пояснения, пункты меню | 4.5:1 там же |
| `faint` | третий план | 3:1 на `surface` |
| `accent` | «работает», фокус, выбор | 4.5:1 на трёх фонах |
| `accent-dim` | выделение текста в поле | — |
| `danger` | «закрыто» | 4.5:1 на трёх фонах |
| `warn` | «внимание» | 4.5:1 на трёх фонах |
| `accent-fill` | заливка главной кнопки | — |
| `on-accent` | подпись на главной кнопке | 4.5:1 на `accent-fill` |
| `warn-fill` | точки и полосы «внимание» | 3:1 на `surface` |

Цвет — `#RRGGBB`, у фоновых слотов можно `#AARRGGBB` с прозрачностью:
карточка станет стеклом над картинкой фона. Текст всегда непрозрачный.

Тема, где хоть одна пара не читается, **не применяется**: программа
назовёт пару и число. Смысл цветов общий для всех тем — зелёный
«работает», красный «закрыто», жёлтый «внимание» — оттенки ваши.

## Шрифты — три

- `ui` — интерфейс;
- `mono` — данные: адреса, задержки, время;
- `display` — только заголовки вкладок.

Системные шрифты Windows пишутся именем. Свой шрифт кладётся в папку
темы и перечисляется в `files` (TTF или OTF, до 8 МБ) — тогда в `ui`,
`mono` или `display` пишется имя его семейства. Только шрифты,
лицензия которых разрешает распространение.

## Фон

- `image` — PNG или JPG в папке темы, до 20 МБ. Не ссылка и не путь.
- `fit` — `cover` (на всё окно с обрезкой), `contain` (целиком)
  или `tile` (замостить).
- `dim` — затемнение цветом `backdrop`, от 0 до 1. Заголовки стоят прямо
  на картинке: текст проверяется по её самому светлому и самому тёмному
  месту, и затемнение — то, чем тема добивается читаемости.
- `blur` — размытие под карточками и меню, 0–80; сам фон остаётся чётким.
  Стекло — это `surface` поверх размытого фона: чем прозрачнее `surface`,
  тем больше видно картинку. Если текст на стекле не читается, программа
  уплотнит его сама; если не помогает и это — тема не применится.

Человек может выключить картинку фона и размытие и затемнить фон сильнее
задуманного («Ещё» → «Оформление»). Светлее задуманного — нельзя:
затемнение и есть то, чем тема проходит проверку.

Отступы, размеры и скругления в тему не входят: они общие, чтобы любая
тема работала на любой вкладке.
