## Что с ними сделано

Исходники — SVG, а WPF его не читает без сторонней библиотеки. Тащить её ради
значков не стоит, поэтому 271 флаг из `flags/4x3` переведён в PNG 120×90:
все разом отрисованы в сетке headless-браузером и нарезаны по точным
координатам ячеек.

Не по превью-листу и не на глаз. Среди флагов есть неразличимые пары — Чад
и Румыния, Монако и Индонезия, — и опознание по картинке дало бы тихую ошибку:
программа уверенно показала бы не ту страну.

Сценарий пересборки живёт в истории этой правки; исходный SVG-пак лежит рядом
в `flag-icons-main/` и в git не попадает.

## Как называются

По коду страны из двух букв в нижнем регистре: `de.png`, `ru.png`, `us.png`.
Код берётся из тега подписки — панели ставят в начало названия пару
региональных букв, и `🇩🇪` это `de`.

Чего нет — не выдумывается: для страны без картинки остаётся значок с буквами.
