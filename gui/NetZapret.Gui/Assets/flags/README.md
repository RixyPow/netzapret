# Флаги

Сюда кладётся пак. Файл на страну, имя — код из двух букв в нижнем регистре:

```
de.png   ru.png   us.png   nl.png   se.png   hk.png
```

Код берётся из тега подписки: панели ставят в начало названия пару
региональных букв, и `🇩🇪` — это `de`.

**Растровые.** Годятся `png`, `jpg`, `gif`, `bmp`. SVG WPF не читает без
сторонней библиотеки, а тащить её ради значков не стоит.

**Размер.** Показываются 26×18 с обрезкой по краям, так что подойдёт любой
пропорциональный; 40×30 или больше — чтобы не мылилось на мониторах
с масштабом.

Чего нет — не выдумывается: для страны без картинки остаётся значок
с буквами. Пустая папка — рабочее состояние.

Файлы подхватываются при сборке (`gui\run.cmd`), перезапуск окна обязателен.
