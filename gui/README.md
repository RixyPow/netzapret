# Окно

Это и есть программа: в архив выпуска идёт только оно. Консоль, рядом с которой
окно когда-то строилось, удалена 23.09.

## Как запустить

```
build.cmd        в корне репозитория — собирает окно и nz, кладёт в build\
build\NetZapret.exe
```

Windows спросит права администратора — они запрошены манифестом. Без них
не поставить драйвер перехвата и не поднять TUN, то есть окно открылось бы
и не смогло сделать ровно то, ради чего открывалось.

Движки окно поднимает само, перезапуская себя с ключом `--supervisor`.
Без окна: `NetZapret.exe --start` и `--stop`.

## Почему своё решение, а не общее

`NetZapret.sln` — библиотеки, `nz` и их тесты; WPF туда не попадает.
Окно и его тесты живут в `gui\NetZapret.Gui.sln`. CI собирает и гоняет оба.

## Где логика

В библиотеках `src\`, а не в окне. Окно — показ и оркестровка: таблицы,
обновление по таймеру, кнопки. Понадобилось решение — ему место в библиотеке,
где им воспользуется и `nz`: две копии одного расчёта расходятся, и за один
вечер 16.09 консоль и окно разошлись четырежды.

## Чего в окне не будет

Вот чего, и почему:

* **Мастеров «настроим за вас».** Проверка видит один момент времени,
  блокировки мигают; всё, что решается само, однажды решится неправильно.
* **Индикаторов без цифр.** Зелёная галочка вместо таблицы вердиктов —
  это ровно то, что отличает нас от любого клиента VPN, и терять это нельзя.
* **Правки `hosts` без подтверждения.** Файл системный, общий, и переживает
  удаление программы.
